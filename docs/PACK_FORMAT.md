# PACK_FORMAT — index payload and manifest contract

One contract for Python (`l0/dac_l0/index/format.py`, `pack/loader.py`), Kotlin
(`android/.../PackIndex.kt`) and Swift (`ios/.../PackIndex.swift`). The executable source of
truth is `format.py`; `golden_format_cases.txt` (generated by `l0/dac_l0/eval/format_golden.py`,
which asserts the Python verdict for every case) must be reproduced by every parser.

## Payload (writer `idx-flat-4`, readers accept `idx-flat-3` and migrate it)

| Part | Content |
|---|---|
| Header | magic `DACL0IDX`, u16 version 1, u16 descriptor bytes, u32 vectors, u32 works, f64 sampling interval (0.1–60 s) |
| Metadata | u32 length (≤ 64 MiB) + strict UTF-8 JSON: no duplicate keys, no NaN/Infinity, exact key sets |
| Body | vectors × (descriptor ‖ 16-byte locator) |
| Locator | u32 work, u16 edition, u32 t_ms, u16 segment = 0, u32 reserved = 0 |

Rules (summary; see `format.py` for the exact list):

- `works[i].work_index == i`; `work_id` unique; IDs match `^[A-Za-z0-9][A-Za-z0-9_.-]{0,63}$` exactly.
- Editions: 1–16 unique IDs per work; **a locator's edition index is the position in that work's
  own edition list** (not a global edition enumeration). `durations_s` matches the editions.
- `episode_id` needs `series_id`; (series, episode) is unique.
- Text fields: 1–200 code points, no control characters. Names: ≤ 16 locale tags. Aliases (v4): ≤ 32 unique.
- Integer fields must be JSON integers (not floats or booleans).
- Locators: work and edition exist, `t_ms ≤ ceil(duration_ms)`, segment and reserved are zero,
  no duplicate (work, edition, t_ms).
- Shared scenes (v4, metadata only): 2–64 members with valid references and
  `0 ≤ start_ms < end_ms ≤ duration_ms`. They document identical footage across works and are
  never used to name a title.
- Migration: an `idx-flat-3` payload reads as v4 with empty aliases and no shared scenes. Writers
  always emit v4. The device engines accept only the DACDHASH family with preprocessing
  `dac-crop-v1+dac-qual-v1+dac-dhash-v1`.

## Manifest (signed development integrity manifest)

Checked by `pack/loader.py` in this order; any failure leaves device state unchanged:
shape and types → signer → compatibility (index format equals payload, preprocessing per
family, generator for development packs, calibration status, descriptor family/bytes) →
versions (`MAJOR.MINOR.PATCH`; pack ≥ its declared minimum; pack ≥ the highest minimum this
device has accepted for the pack ID) → size and hash → region method → rights epoch →
validity window (parsed instants with explicit offsets; `valid_until` exclusive) → release
gate → payload consistency (family, counts, sampling interval, indexed hours).

Development vs licensed: development packs (synthetic self-grant) may load on untrusted time
only without an expiry and may never claim `CALIBRATED`. Licensed packs need an expiry and
trusted time; release mode needs `CALIBRATED`.

## Installed state (`pack/store.py`)

Immutable slots per pack; `state.json` replace is the single commit point; `floors.json`
keeps epoch and version floors that a restored older state cannot lower; startup recovery
removes every unreferenced slot, staging directory and temp file. Verified by killing a child
process with `os._exit` before every I/O step of an install.
